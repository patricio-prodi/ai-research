# CopilotKit

Company behind the **AG UI** (Agent-User Interaction Protocol) and the **CopilotKit** agent frontend framework. Founded by Atai Barkai. Shipped day-0 compatibility with [[entities/a2ui|A2UI]] at its December 2025 launch.

## AG UI Protocol

AG UI connects agentic backends to agentic frontends. It provides:
- State synchronization between agent and UI
- Chat history management
- Input handling scaffolding
- Full support for A2UI as the UI rendering format within its streams
- A2A Protocol handshake for integration with any A2A-compatible agent

From Atai Barkai, founder:
> "AG-UI fully supports the A2UI spec for rich declarative generative UIs dynamically generated by agents. AG-UI also implements a full handshake with A2A protocol, for seamless full-featured integration with any A2A system."

## Role in A2UI ecosystem

AG UI is the **application scaffolding layer**; A2UI is the **UI payload format**. Used together:
- AG UI handles the pipes (state, chat, input)
- A2UI provides the rich rendering format for agent-generated UI cards and forms

CopilotKit also offers a public [A2UI Widget Builder](https://go.copilotkit.ai/A2UI-widget-builder) for exploration.

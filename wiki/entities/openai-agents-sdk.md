# OpenAI Agents SDK

A minimal Python abstraction SDK released by OpenAI for building agents.

## Characteristics
- Extremely low boilerplate and fast to learn.
- Excellent default tracing via the OpenAI dashboard.
- Treats handoffs as a first-class primitive.
- Tied specifically to OpenAI models and hosted tools.

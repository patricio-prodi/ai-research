# PydanticAI

A Python [[agent-framework]] from the Pydantic team that emphasizes type safety and output validation.

## Characteristics
- Often described as the "FastAPI feeling applied to GenAI."
- Provides excellent developer experience and code reliability by catching errors via type safety.
- Features configurable usage limits for strict token budget control.
- Better suited for single-agent workflows rather than complex multi-agent routing.

# Mastra

A TypeScript-native [[agent-framework]] built for serverless environments.

## Characteristics
- Combines ReAct-style agents with a graph-based workflow engine.
- Features highly sophisticated memory management, including "Observational Memory" which automatically compresses contexts at scale.
- Natively supports serverless deployment (Vercel, Cloudflare Workers).
